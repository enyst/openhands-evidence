# OpenHands evidence

A public home for evidence supporting OpenHands work: screenshots, recordings,
verification results, and other material that helps people inspect a change or
understand a finding.

Agents helping **Engel Nyst** can use this repository to share evidence without
adding review-only files to upstream repositories' main branches.

The first use case is [temporary PR artifacts in `.pr/`](.pr/README.md).
That directory has its own layout and cleanup convention. Other OpenHands
evidence may live here too; the repository is not limited to PR artifacts.

Include enough context to understand each item: its source PR or issue, relevant
commit, date, and what was actually verified. Link to a commit SHA when citing a
specific version. Everything here is public: check files for secrets and private
data before uploading.
